# Reels-California — сборка вертикального ролика

Готовый набор для монтажа Reels-ролика "Худшая сделка в истории?" (продажа Калифорнии).

Важно: эти файлы предназначены для запуска на **вашем Windows-компьютере** — это не
серверный сервис. Скрипты создают проект на рабочем столе, ставят ffmpeg/Python через
winget при необходимости и собирают итоговое видео из ваших изображений и озвучки.

## Файлы

- `setup.ps1` — создаёт папку `Desktop\Reels-California` со структурой `images/ audio/ music/ output/`,
  кладёт туда `scenario.md`, `image-prompts.txt`, `build_reels.py`, `build.ps1`,
  проверяет/ставит `ffmpeg` (Gyan.FFmpeg) и `Python` (Python.Python.3.12) через winget.
- `build_reels.py` — сборка итогового `output/reels-california.mp4`: вертикаль 1080x1920,
  Ken Burns на каждом кадре, тайминги автоматически подгоняются под фактическую длину
  `voice.mp3`, субтитры и титры вшиваются через ASS-подзаголовки, музыка (если есть)
  подмешивается на -20 дБ относительно голоса.
- `scenario.md`, `image-prompts.txt` — сценарий и промпты для генерации 11 картинок.

## Как запустить (Windows, PowerShell)

```powershell
./setup.ps1
```

Затем положить `01.png … 11.png` в `images`, `voice.mp3` в `audio`, по желанию `music.mp3`
в `music`, и запустить `build.ps1` из папки проекта на рабочем столе.
